# Зниклий кіт — рівень 1

A playable demo level: a child assembles an agent-creature, watches it fail to find a lost kitten
because it has no memory, installs the memory block, and watches it succeed.

Open it: https://xelagate.github.io/lost-cat-demo/

One self-contained page — no build step, no backend, no tracking. It stores nothing and sends
nothing anywhere. Add `?selftest=1` to the URL to check the walk simulation in the browser.
